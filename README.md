# kr1-html-css-shop — магазин наушников «Тембр»

## Контрольная работа №1
Тема: «HTML и CSS: разработка многостраничного сайта».
В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина наушников «Тембр» (без фреймворков).

## Ссылка на опубликованный проект
GitHub Pages: https://USERNAME.github.io/kr1-html-css-shop/

## Структура проекта
```
kr1-html-css-shop/
├── index.html      # главная: hero, преимущества, популярные товары, контакты
├── catalog.html    # каталог: фильтры (макет), сетка карточек
├── product.html    # карточка товара: таблица, модальное окно <dialog>
├── order.html      # форма заявки
├── contacts.html   # контакты, часы работы, FAQ
├── css/style.css   # все стили (переменные, БЭМ, Flex, Grid)
├── js/main.js      # только открытие/закрытие модального окна
├── images/         # изображения
├── README.md
└── .gitignore
```

## Используемые технологии
HTML5 (семантика), CSS3 (переменные, Flexbox, Grid, position, :hover, :focus-visible), БЭМ, минимальный JS для `<dialog>`, GitHub Pages.

## Как посмотреть
1. Склонировать репозиторий или скачать архив.
2. Открыть `index.html` в браузере (или перейти по ссылке GitHub Pages).

## Обязательные страницы
`index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html` — единое меню, якорные ссылки (`#advantages`, `#popular`, `#contacts`), общий `css/style.css`.

## Самостоятельные доработки
- собственная визуальная концепция (палитра, шрифты);
- хлебные крошки и sticky-фильтр каталога;
- бейджи и модификатор `product-card--discount`;
- блок FAQ на странице контактов;
- кнопка «Наверх» (position: fixed);
- модальное окно `<dialog>` с формой заявки;
- подсветка невалидных полей формы, видимый фокус.
